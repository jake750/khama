## قواعد الكتابة في التقرير

- **لغة محايدة** (A-92): لا «ممتاز» ولا «احترافي». الادعاء يُتبع برقم أو مرجع. نصوص README تسويقية فلا تُنقل كما هي (A-91).
- **المصطلحات** (A-93): العربي أولًا ثم الإنجليزي بين قوسين عند أول ذكر، ثم العربي وحده. القائمة في [glossary.md](glossary.md) وفي [docs/STYLE.md](../STYLE.md).
- **الأرقام والوحدات** (A-94): أرقام غربية (0–9)؛ ميغابايت بالرمز MB وغيغابايت GB؛ الدقة بالارتفاع (1080p) والأبعاد عند الحاجة (1920×1080)؛ الزمن بالثانية (ث) والدقيقة (د).
- **الأشكال والجداول** (A-66): «الشكل 4.2: عنوان» تحت الشكل، و«الجدول 6.1: عنوان» فوق الجدول، وكل شكل يُذكر في النص قبله. المصدر تحت الشكل إن لم يكن من إنتاجك.
- **الاتساق مع الكود** (A-95): التقرير يصف النسخة الموسومة للمناقشة ([defense.md](defense.md)). قبل التسليم: أعد تشغيل القياسات (§6) وراجع كل ادعاء في §4 مقابل الكود.
- **المراجعة اللغوية** (A-69): نصوص الواجهة تخضع لاختبارين آليين (لا إنجليزية منسية، لا ثلاث نقاط) ولدليل [STYLE.md](../STYLE.md). التقرير نفسه يمرّ على مدقق لغوي بشري قبل الطباعة.
- **التنسيق** (A-102): قالب الجامعة (الهوامش، والخط، والترقيم، والغلاف) يُطبَّق عند النقل إلى Word أو LaTeX.
