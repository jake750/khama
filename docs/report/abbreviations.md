# قائمة الاختصارات

الاختصارات الواردة في التقرير مرتّبة أبجديًا. شرح المفاهيم نفسها في المسرد.

| الاختصار | بالإنجليزية | بالعربية |
|---|---|---|
| AAC | Advanced Audio Coding | ترميز الصوت المتقدم |
| AMF | Advanced Media Framework (AMD) | واجهة ترميز الفيديو بعتاد AMD |
| AV1 | AOMedia Video 1 | مرمِّز فيديو مفتوح |
| BD-rate | Bjøntegaard Delta rate | فرق معدل البت بالجودة نفسها |
| CFR / VFR | Constant / Variable Frame Rate | معدل إطارات ثابت / متغيّر |
| CI | Continuous Integration | التكامل المستمر |
| CRF | Constant Rate Factor | معامل الجودة الثابتة في x264 وx265 |
| CSP | Content Security Policy | سياسة أمان المحتوى |
| DRM | Digital Rights Management | إدارة الحقوق الرقمية |
| DSR | Design Science Research | منهج علم التصميم |
| DTW | Dynamic Time Warping | المطابقة الزمنية المرنة |
| F₁ | F₁ score | المتوسط التوافقي للدقة والاسترجاع |
| FR / NFR | (Non-)Functional Requirement | متطلب وظيفي / غير وظيفي |
| GPL | GNU General Public License | رخصة جنو العمومية |
| HEVC | High Efficiency Video Coding (H.265) | الترميز عالي الكفاءة |
| HSV | Hue, Saturation, Value | نموذج الألوان: الصبغة والتشبّع والقيمة |
| H1–H8 | Hypotheses | فرضيات التقرير (§1.5) |
| IPC | Inter-Process Communication | التواصل بين العمليات (بين الواجهة وRust) |
| IQR | Interquartile Range | المدى بين الربعين |
| KLM | Keystroke-Level Model | نموذج مستوى المفاتيح |
| MAD | Median Absolute Deviation | الانحراف المطلق الوسيط |
| MAE | Mean Absolute Error | متوسط الخطأ المطلق |
| MDX-Net | Multi-Dilated eXtended network | معمارية نموذج فصل الصوت المستعمل |
| MUSDB18 | Music Source Separation DB (2018) | مجموعة بيانات فصل الموسيقى |
| NVENC | NVIDIA Encoder | مرمِّز الفيديو بعتاد NVIDIA |
| O1–O8 | Objectives | الأهداف القابلة للقياس (§1.4) |
| ONNX | Open Neural Network Exchange | صيغة مفتوحة لتبادل النماذج العصبية |
| PCHIP | Piecewise Cubic Hermite Interpolating Polynomial | الاستيفاء التكعيبي الرتيب |
| PSNR | Peak Signal-to-Noise Ratio | نسبة ذروة الإشارة إلى الضجيج |
| QSV | Intel Quick Sync Video | مرمِّز الفيديو بعتاد Intel |
| RQ1–RQ4 | Research Questions | أسئلة البحث (§1.3) |
| RTL | Right-to-Left | من اليمين إلى اليسار |
| SBOM | Software Bill of Materials | قائمة مكوّنات البرنامج |
| SDR / SIR / SAR | Signal-to-Distortion / -Interference / -Artefacts Ratio | نِسب الإشارة إلى التشويه / التداخل / الآثار |
| SHA-256 | Secure Hash Algorithm, 256 bits | دالة البصمة المستعملة لفحص الملفات |
| SNR | Signal-to-Noise Ratio | نسبة الإشارة إلى الضجيج |
| SSIM | Structural Similarity Index | مؤشر التشابه البنيوي |
| STFT | Short-Time Fourier Transform | تحويل فورييه قصير الزمن |
| STRIDE | Spoofing, Tampering, Repudiation, Information disclosure, Denial of service, Elevation of privilege | تصنيف التهديدات الست |
| SUS | System Usability Scale | مقياس قابلية الاستخدام |
| UML | Unified Modeling Language | لغة النمذجة الموحّدة |
| VAD | Voice Activity Detection | كشف وجود الكلام |
| VMAF | Video Multimethod Assessment Fusion | مقياس Netflix لجودة الفيديو المُدرَكة |
| WCAG | Web Content Accessibility Guidelines | إرشادات إتاحة محتوى الويب |
