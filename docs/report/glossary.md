# المسرد

(A-48) المصطلح العربي كما يُستعمل في التقرير، ثم الإنجليزي. الجدول الأول لمصطلحات الفيديو والتطبيق، والثاني لمصطلحات المحاور البحثية والقياس (A-51). الاختصارات وحدها في قائمة الاختصارات في الصفحات التمهيدية.

| المصطلح | بالإنجليزية | التعريف |
|---|---|---|
| معدل إطارات ثابت | Constant Frame Rate (CFR) | كل إطار يظهر بعد الفاصل الزمني نفسه (مثل 1/30 ث). ما تتوقعه برامج المونتاج. |
| معدل إطارات متغيّر | Variable Frame Rate (VFR) | الفاصل بين الإطارات يتغيّر، كما في تسجيلات الهاتف وتسجيل الشاشة. يسبب انزياح الصوت في بعض البرامج. |
| كودك | Codec | طريقة ضغط الصورة أو الصوت وفكّها (H.264، ProRes، AAC). |
| حاوية | Container | الملف الذي يجمع المسارات (فيديو، صوت، ترجمة): MP4، MOV، MKV. |
| إعادة التغليف | Remux / Rewrap | نقل المسارات إلى حاوية أخرى دون إعادة ضغط. سريع وبلا فقد. |
| H.264 / H.265 / AV1 | — | كودكات ضغط للتوزيع، من الأقدم الأوسع دعمًا إلى الأحدث الأصغر حجمًا. |
| ProRes | Apple ProRes | عائلة كودكات من Apple للمونتاج: ملفات كبيرة سهلة التقليب. |
| DNxHR | Avid DNxHR | مقابل ProRes من Avid، مقروء في Resolve المجاني على Linux. |
| بروكسي | Proxy | نسخة خفيفة من الملف للمونتاج على جهاز ضعيف، تُستبدل بالأصل عند التصدير. |
| صيغة | Preset | مجموعة إعدادات تحويل جاهزة باسم واحد. |
| جدول ألوان | LUT (Look-Up Table) | تحويل ألوان جاهز (مثلًا من Log إلى Rec.709). |
| LUFS | Loudness Units relative to Full Scale | وحدة قياس جهارة الصوت كما تُدرَك، معيار EBU R128. |
| تحويل فورييه قصير الزمن | Short-Time Fourier Transform (STFT) | تقسيم الصوت إلى نوافذ قصيرة وحساب طيف كل نافذة. |
| نافذة Hann | Hann window | دالة تُضرب بها كل نافذة قبل STFT لتقليل التسرّب الطيفي عند حوافها. |
| فصل المصادر | Source separation | استخراج مصدر (صوت بشري، موسيقى) من تسجيل مختلط. |
| نسبة الإشارة إلى الضجيج | Signal-to-Noise Ratio (SNR) | نسبة طاقة الإشارة المرجعية إلى طاقة الخطأ، بالديسيبل. |
| ONNX | Open Neural Network Exchange | صيغة مفتوحة لنماذج التعلّم الآلي تعمل في ONNX Runtime دون إطار التدريب. |
| IPC | Inter-Process Communication | التواصل بين الواجهة (WebView) والنواة (Rust) عبر أوامر وأحداث. |
| أداة مرافقة | Sidecar | برنامج خارجي يُشحن مع التطبيق ويشغّله (yt-dlp، FFmpeg). |
| WebView | — | محرّك المتصفح الذي يوفّره النظام لعرض واجهة HTML داخل تطبيق. |
| RTL / BiDi | Right-to-Left / Bidirectional | كتابة من اليمين إلى اليسار، وخلط الاتجاهين في سطر واحد. |
| إدارة الحقوق الرقمية | Digital Rights Management (DRM) | تشفير يمنع نسخ المحتوى المدفوع. |
| SSIM | Structural Similarity Index | مقياس تشابه بين صورتين من 0 إلى 1؛ فوق 0.95 يصعب تمييز الفرق عادة. |
| SBOM | Software Bill of Materials | قائمة بكل مكوّنات البرنامج ونسخها. |
| CI | Continuous Integration | فحص الكود وبناؤه آليًا عند كل تغيير. |

## مصطلحات المحاور البحثية والقياس

| المصطلح | بالإنجليزية | التعريف |
|---|---|---|
| منهج علم التصميم | Design Science Research (DSR) | منهج يبني أثرًا (artifact) يحلّ مشكلة حقيقية، ثم يقيّمه، ثم يستخلص منه معرفة تنتقل إلى غيره [48]، [49]. |
| حدّ اللقطة | Shot boundary | موضع الانتقال من لقطة إلى أخرى: قطع حاد بين إطارين متتاليين، أو انتقال تدريجي (مزج، تلاشٍ) يمتد على عدة إطارات. |
| عتبة متكيّفة | Adaptive threshold | عتبة تُحسب من الإشارة نفسها، في نافذة منزلقة أو من توزيع المقطع كله، بدل رقم ثابت لكل المقاطع. |
| الانحراف المطلق الوسيط | Median Absolute Deviation (MAD) | وسيط المسافات بين القيم ووسيطها. مضروبًا في 1.4826 يقدّر الانحراف المعياري لتوزيع طبيعي، ولا تحرّكه قيمة شاذة واحدة [55]. |
| الدقة والاسترجاع وF₁ | Precision, Recall, F₁ | الدقة P: نسبة الصحيح مما أعلنه الكاشف. الاسترجاع R: نسبة ما وجده من الأحداث الحقيقية. F₁ = 2PR/(P+R)، متوسطهما التوافقي. |
| دراسة الإزالة | Ablation study | إزالة مكوّن واحد من الطريقة في كل مرة وقياس ما ينقص، لمعرفة ما يضيفه كل مكوّن. |
| فصل الضبط عن الاختبار | Dev/test split | ضبط المعاملات على جزء من البيانات، والإبلاغ عن النتيجة على جزء لم يُستعمل في الضبط. |
| التحقق بترك واحد | Leave-one-out | يُبنى الجدول أو النموذج من كل العيّنات إلا واحدة ثم يُقاس عليها، ويتكرر ذلك لكل عيّنة. في التقرير: ترك مقطع واحد (leave-one-clip-out). |
| إعادة المعاينة | Bootstrap | سحب عيّنات بالإرجاع من البيانات آلاف المرات لتقدير فترة ثقة دون افتراض شكل التوزيع [50]. |
| فترة Wilson | Wilson score interval | فترة ثقة لنسبة (مثل الاسترجاع) تبقى صالحة مع العيّنات الصغيرة والنسب القريبة من 0 أو 1 [53]. |
| اختبار McNemar | McNemar's test | يقارن طريقتين على الحالات نفسها، ويعتمد على الحالات التي اختلفتا فيها فقط [51]. |
| اختبار Wilcoxon المزدوج | Wilcoxon signed-rank test | اختبار لا معلمي لفرق قياسين على العيّنات نفسها، يعمل برتب الفروق لا بقيمها [54]. |
| تصحيح Holm | Holm–Bonferroni correction | تعديل قيم p عند إجراء عدة مقارنات معًا، حتى لا يظهر فرق «دالّ» بالصدفة وحدها [52]. |
| معامل الجودة الثابتة | Constant Rate Factor (CRF) | إعداد الجودة في x264 وx265: رقم أصغر يعني جودة أعلى وملفًا أكبر، ومعدل البت يتبع صعوبة المشهد. |
| الترميز بالعتاد | Hardware encoding | ترميز بدائرة مخصّصة في المعالج الرسومي (Quick Sync، NVENC، AMF): أسرع بكثير من الترميز البرمجي، وجودته عند الرقم الاسمي نفسه تختلف عنه (§6.14.2). |
| PSNR | Peak Signal-to-Noise Ratio | 10·log₁₀(255²/MSE) بالديسيبل، حيث MSE متوسط مربع الفرق بين الصورتين. بسيط ولا يطابق الإدراك دائمًا. |
| VMAF | Video Multimethod Assessment Fusion | مقياس جودة فيديو من Netflix يجمع خصائص بصرية في درجة من 0 إلى 100 بانحدار مدرَّب على تقييمات بشرية؛ 93–95 تُعدّ «شفافة بصريًا» [33]. |
| BD-rate | Bjøntegaard Delta rate | متوسط فرق معدل البت بين مرمِّزين عند الجودة نفسها، من منحنيي (لوغاريتم المعدل، الجودة) على مجال الجودة المشترك. قيمته السالبة توفير [34]. |
| PCHIP | Piecewise Cubic Hermite Interpolating Polynomial | استيفاء تكعيبي يحافظ على رتابة النقاط المقيسة فلا يتجاوزها؛ يُستعمل في حساب BD-rate [56]. |
| SDR / SIR / SAR | Signal-to-Distortion / -Interference / -Artefacts Ratio | مقاييس BSS Eval لفصل المصادر بالديسيبل: نسبة الإشارة المرجعية إلى كل الخطأ، وإلى ما تسرّب من المصادر الأخرى، وإلى الآثار التي أدخلها الفصل نفسه [25]. |
| MUSDB18 | MUSDB18 corpus | مجموعة أغانٍ بمسارات منفصلة (صوت، طبول، باص، غير ذلك)، معيار تقييم فصل الموسيقى، ورخصتها للاستعمال الأكاديمي فقط [26]. استُعملت أغاني الاختبار الخمسون (§6.14.3). |
| كشف الكلام | Voice Activity Detection (VAD) | تحديد أجزاء التسجيل التي فيها كلام، بعتبة على الطاقة كما في خامة، أو بنموذج مثل Silero VAD [43]. |
| المطابقة الزمنية المرنة | Dynamic Time Warping (DTW) | محاذاة متتاليتين مختلفتي السرعة بأقل كلفة مجمّعة [57]. في whisper.cpp تُحاذى أوزان الانتباه مع إطارات الصوت فيُعرف وقت كل كلمة. |
| TextTiling | — | طريقة Hearst لتقسيم نص طويل إلى مواضيع: يُقاس تداخل المفردات بين كتلتين متجاورتين، ويُقطع حيث يهبط [38]. |
| نموذج مستوى المفاتيح | Keystroke-Level Model (KLM) | تقدير زمن مهمة لمستخدم متمرّس بجمع أزمنة ثابتة لكل عملية (ضغطة، تأشير، تفكير) [58]. |
| MUSHRA | MUltiple Stimuli with Hidden Reference and Anchor | اختبار استماع يقيّم فيه المستمعون عدة نسخ من المقطع نفسه مقابل مرجع مخفي. لم يُجرَ في المشروع (§8.2). |
